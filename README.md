# 蒜种吊束阴干换位引导台

面向把自留蒜头**连秧带回通风棚、分畦阴干后再剪秧**的家庭种植者的纯前端引导应用。
资料与计算全部留在本机浏览器（IndexedDB），无后端、无网络依赖，可在本机浏览器原生运行。

## 作业流程

录入畦批 → 绘制横杆与禁碰区 → 设置引导参数 → 作业台逐步引导：

1. **隔离**：录入时检出破皮/霉斑的蒜头整批先进隔离席，不参与分束；
2. **挂牌**：标签必须在离开分拣席前固定（束号格式 `畦号-序号`，不同畦号绝不混束）；
3. **分束**：按单束枚数扎绳，末束不足数自动标记；
4. **复称**：登记实重与实点枚数，超过单钩载重的束不得进入上杆；
5. **左右交替上杆**：严格左（北）—右（南）交替，SVG 高亮本次蒜束、建议钩位与手持送束方向；
6. **颈干复核**：颈部仍软只延后该束剪秧，**不释放挂位**；
7. **剪秧收束**：颈干通过后剪秧下杆，挂位空出。

## 强制规则（由引擎自动校验）

- 不同畦号不得同束；
- 标签须在离开分拣席前固定（未挂牌不能分束）；
- 挂钩不得超载（复称重量 > 钩载即拦截）；
- 蒜束外廓不得重叠、不得侵入墙地禁碰区、底部不得低于离地净距；
- 成对挂钩左右载荷差不得越限；
- 绳结松动：先落到**空置垫席**重绑，确认后才能继续；
- 上杆后发现霉斑：**整束隔离、释放挂位、自动补排未挂部分**；
- 结构或批次资料改变：相关蒜束步骤/挂位标记失效，复核通过或重排后恢复；
- 误确认可随时**撤回**（保留最近 50 步快照）。

## 页面

| 页面 | 内容 |
| --- | --- |
| 畦批录入 | 畦号、枚数、带秧重量、颈部状态、破皮/霉斑；隔离席清单 |
| 横杆结构 | 棚体/横杆尺寸、挂位数、绳长、束高、墙地禁碰区；SVG 实时俯视示意与校核 |
| 引导参数 | 单束枚数、钩载、外廓半径、相邻净距、左右载荷差上限 |
| 作业台 | 六步工序引导、候选钩位与手持方向高亮、垫席重绑、霉斑隔离、日志 |
| 标签打印 | 按束打印挂杆标签（调用浏览器打印，仅输出标签区） |

## 运行

```bash
npm install
npm run dev      # 本机开发，浏览器打开 http://localhost:5173
npm run build    # 类型检查 + 生产构建到 dist/
npm run preview  # 预览生产构建
```

构建产物为纯静态文件，可直接用任意静态服务器打开 `dist/` 目录。
清除浏览器站点数据即删除全部作业资料；应用内也提供“清空重来”（可撤回）。

## 技术栈

React 18 + TypeScript + Vite，布局与挂位可视化全部用手写 SVG，存储用 IndexedDB（自动防抖保存）。
核心规则集中在 `src/engine.ts`（纯函数）与 `src/store.tsx`（reducer），便于核对。
